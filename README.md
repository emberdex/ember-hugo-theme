## Installation

Add Ember to your Hugo site's `themes` directory:

```bash
git submodule add https://github.com/emberdex/ember-hugo-theme.git themes/ember
```

Or clone it directly:

```bash
git clone https://github.com/emberdex/ember-hugo-theme.git themes/ember
```

Then specify `theme = 'ember'` in your site's `hugo.toml`.

---

## Configuration

Example `hugo.toml`:

```toml
baseURL = 'https://blog.tobes.dev/'
title = "Example Blog"
theme = 'ember'

[pagination]
  pagerSize = 10

[params]
  author = "emberdex"
  subtitle = "Example subtitle"
  description = "Example description"
  mode = "auto"

  [params.social]
    github = "https://github.com/emberdex"
    twitter = "https://x.com/username"
    mastodon = "https://mastodon.social/@username"
    linkedin = "https://linkedin.com/in/username"
    email = "you@example.com"

[menus]
  [[menus.main]]
    name = 'Home'
    pageRef = '/'
    weight = 10

  [[menus.main]]
    name = 'Posts'
    pageRef = '/posts'
    weight = 20

  [[menus.main]]
    name = 'Tags'
    pageRef = '/tags'
    weight = 30

[markup]
  [markup.highlight]
    noClasses = false
    guessSyntax = true
    lineNos = false
    tabWidth = 2
```

## Frontmatter Options

For individual blog posts:

```yaml
---
title: Example title
description: Example description
date: 2026-01-01
draft: false
tags: ["rest-api", "example"]
toc: true # set to false to disable table of contents
toc_open: false # set to true to expand table of contents by default
---
```
